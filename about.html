Acerca de este proyecto

La Pokédex Web nace como un proyecto hecho por fans, con el objetivo de compartir información básica sobre distintas especies de Pokémon.

Incluye datos sobre tipos elementales, evoluciones y curiosidades de las diferentes generaciones de juegos.

Este sitio fue creado con fines educativos, como parte de una práctica de control de versiones con Git y GitHub.
